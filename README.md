# Line-Following-Car
Car that Follows a Line


<h1>Line Following Car</h1>


<h2>Description</h2>
Project consists of an autonomous robot designed to navigate black line tracks using photoresistor-based sensing and PID control. The system demonstrates fundamental control theory and embedded systems integration, with photoresistors detecting contrast between black lines and white surfaces (0-20 vs 200-400 analog values). A custom PCB designed in KiCad replaces traditional breadboard implementation, mounting the sensor array and LED illumination system. The chassis and light shield were designed in Fusion360 and 3D printed to provide structural integration and eliminate ambient light interference. The PID controller (P=10.0, D=20.0) processes sensor inputs to adjust motor speeds for smooth path tracking and sharp turn navigation. Hardware challenges including PCB design flaws and chassis mounting issues were debugged and resolved through iterative testing. The robot successfully completed track navigation demonstrations, showcasing the integration of custom hardware design, control algorithms, and mechanical systems.
